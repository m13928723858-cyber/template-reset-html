## 🎯 这是什么？

一个基于AI的智能营销页面生成系统，只需输入产品信息，即可自动生成完整的产品对比评测页面。

### ✨ 核心功能

- 🤖 **AI自动生成** - 竞品分析、文案创作、图片爬取
- 📄 **专业模板** - 基于真实营销页面优化
- 🖼️ **本地图片** - 图片下载到本地，加载更快
- 🎨 **完全自动** - 无需手动编辑，一键生成

### 🚀 快速开始

**只需3步**：

1. **输入产品信息**
   ```
   产品名称：Ororo Heated Vest
   产品类型：heated vest
   ```

2. **点击生成**
   ```
   等待60秒...
   ```

3. **下载结果**
   ```
   获得完整的HTML网页
   ```

```bash
cd ../frontend

```

## ❓ 常见问题

### Q: 需要编程知识吗？

**A**: 完全不需要！只需要：
1. 会双击运行程序
2. 会在浏览器中填写表单
3. 会下载和解压文件

### Q: 生成一次需要多长时间？

**A**: 约60秒，包括：
- 生成竞品：4秒
- 生成文案：35秒
- 爬取图片：18秒
- 填充模板：1秒

### Q: 需要付费吗？

**A**: 系统本身免费，但需要：
- AI服务API密钥（可能需要付费）
- 每次生成消耗约4,600个Token

### Q: 生成的页面可以商用吗？

**A**: 可以，生成的页面完全属于您，可以：
- 上传到自己的网站
- 修改内容和样式
- 用于商业推广

### Q: 支持哪些语言？

**A**: 目前支持：
- 英文（推荐）
- 中文（部分支持）

### Q: 可以自定义模板吗？

**A**: 可以，但需要一定的HTML/CSS知识。
详见《项目移交文档》的高级功能部分。

## 🐛 故障排查

### 问题1：启动失败

**症状**：双击启动脚本后窗口闪退

**解决**：
1. 检查Python和Node.js是否安装
2. 运行 `diagnose.bat` 查看诊断报告
3. 查看《使用手册》的常见问题部分

### 问题2：生成失败

**症状**：点击生成后报错

**解决**：
1. 检查API密钥是否正确
2. 检查网络连接
3. 查看浏览器控制台错误信息

### 问题3：图片无法显示

**症状**：生成的页面中图片不显示

**解决**：
1. 检查网络连接
2. 重新生成页面
3. 上传自己的产品图片

### 更多问题？

运行诊断工具：
```bash
diagnose.bat
```

或查看完整的故障排查指南：
