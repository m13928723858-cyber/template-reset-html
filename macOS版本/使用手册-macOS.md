## 🔧 首次安装

### 第一步：安装Python

1. **打开浏览器**，访问：https://www.python.org/downloads/

2. **点击下载按钮**（Download Python 3.x.x）

3. **运行安装程序**
   - 打开下载的 `.pkg` 文件
   - 按照安装向导操作
   - 点击 "继续" → "安装"

4. **等待安装完成**（约2-3分钟）

5. **验证安装**
   - 按 `Command + 空格`
   - 输入 `Terminal`，回车
   - 输入 `python3 --version`
   - 应该显示：`Python 3.11.0` 或类似版本

---

### 第二步：安装Node.js

1. **打开浏览器**，访问：https://nodejs.org/

2. **下载LTS版本**（左边的绿色按钮）

3. **运行安装程序**
   - 打开下载的 `.pkg` 文件
   - 使用默认选项
   - 一路点击 "继续"

4. **等待安装完成**（约2-3分钟）

5. **验证安装**
   - 打开终端（同上）
   - 输入 `node --version`
   - 应该显示：`v18.17.0` 或类似版本

---

### 第三步：配置API密钥

1. **打开Finder**
   ```
   桌面 → 网页重置 → backend
   ```

2. **显示隐藏文件**
   - 按 `Command + Shift + .`（点号）
   - 现在可以看到 `.env` 文件

3. **打开文件**
   - 右键点击 `.env`
   - 选择 "打开方式" → "文本编辑"

4. **找到这一行**：
   ```
   DOLPHIN_API_KEY=你的API密钥
   ```

5. **替换密钥**
   - 删除 `你的API密钥`
   - 粘贴您的实际API密钥
   - 例如：`DOLPHIN_API_KEY=sk-abc123def456...`

6. **保存文件**
   - 按 `Command + S`
   - 关闭文本编辑

---

### 第四步：安装依赖包

1. **打开终端**
   - 按 `Command + 空格`
   - 输入 `Terminal`，回车

2. **进入项目目录**
   ```bash
   cd ~/Desktop/网页重置
   ```

3. **添加执行权限**
   ```bash
   chmod +x install-dependencies.sh
   ```

4. **运行安装脚本**
   ```bash
   ./install-dependencies.sh
   ```

5. **等待安装**
   - 显示安装进度
   - 大约需要5-10分钟
   - ⚠️ 不要关闭终端

6. **看到提示**
   ```
   ✅ 所有依赖安装完成！
   ```

## 🚀 每日使用

### 启动系统

1. **打开终端**
   - 按 `Command + 空格`
   - 输入 `Terminal`，回车

2. **进入项目目录**
   ```bash
   cd ~/Desktop/网页重置
   ```

3. **添加执行权限**（首次需要）
   ```bash
   chmod +x start-services.sh
   ```

4. **运行启动脚本**
   ```bash
   ./start-services.sh
   ```

5. **等待启动**
   - 会打开两个新的终端窗口
   - 窗口1：后端服务
   - 窗口2：前端服务
   - 等待约10秒

6. **看到提示**
   ```
   窗口1: Uvicorn running on http://0.0.0.0:8000
   窗口2: Local: http://localhost:5173/
   ```

7. **系统启动成功！**
   - ⚠️ 不要关闭这两个终端窗口
   - 可以最小化

---

### 打开界面

1. **打开浏览器**（推荐Chrome或Safari）

2. **输入网址**
   ```
   http://localhost:5174/
   ```

3. **看到界面**
   - 标题：AI智能页面生成系统
   - 三个输入框
   - 一个生成按钮

---

### 生成页面

#### 步骤1：填写产品信息

**输入框1：Winner产品名称**
```
示例：Ororo Heated Vest
```
- 填写您的产品完整名称
- 包括品牌和型号

**输入框2：产品类型**
```
示例：heated vest
```
- 填写产品类别
- 用英文，小写
- 例如：shoes, jacket, coffee machine

**输入框3：上传产品图片（可选）**
- 点击"选择文件"
- 选择您的产品图片
- 建议尺寸：600x600像素
- 支持格式：JPG、PNG

#### 步骤2：生成页面

1. **点击"生成页面"按钮**

2. **等待处理**
   - 进度条会显示当前状态
   - 约需要60秒
   - 不要刷新页面
   - 不要重复点击

3. **查看进度**
   ```
   ⏳ 正在生成竞品... (10%)
   ⏳ 正在生成营销文案... (30%)
   ⏳ 正在爬取产品图片... (60%)
   ⏳ 正在填充模板... (85%)
   ✅ 处理完成！(100%)
   ```

#### 步骤3：下载结果

1. **点击"下载结果"按钮**

2. **保存ZIP文件**
   - 选择保存位置（建议桌面）
   - 文件名：`brand_swap_xxxxx.zip`

3. **解压文件**
   - 双击ZIP文件自动解压
   - 或右键 → "打开方式" → "归档实用工具"

4. **查看结果**
   - 打开解压后的文件夹
   - 双击 `index.html`
   - 在浏览器中查看生成的页面

---

### 停止系统

1. **关闭浏览器标签页**

2. **停止服务**
   - 切换到两个终端窗口
   - 在每个窗口中按 `Control + C`
   - 看到提示后直接回车

3. **关闭终端窗口**
   - 按 `Command + Q`

## ❓ 常见问题

### Q1: 提示"Permission denied"

**原因**：脚本没有执行权限

**解决方法**：
```bash
chmod +x *.sh
```

**详细步骤**：
```
1. 打开终端
2. 进入项目目录：cd ~/Desktop/网页重置
3. 添加权限：chmod +x *.sh
4. 重新运行脚本
```

---

### Q2: 提示"command not found: python3"

**原因**：Python未正确安装

**解决方法**：
1. 重新安装Python
2. 确保安装的是Python 3.8+
3. 重启终端

**验证安装**：
```bash
python3 --version
which python3
```

---

### Q3: 提示"command not found: node"

**原因**：Node.js未正确安装

**解决方法**：
1. 重新安装Node.js
2. 选择LTS版本
3. 重启终端

**验证安装**：
```bash
node --version
which node
```

---

### Q4: 浏览器显示"无法访问此网站"

**原因**：服务未启动或端口被占用

**解决方法**：

**检查服务是否启动**：
```
1. 查看两个终端窗口
2. 确认没有错误信息
3. 看到"Uvicorn running"说明启动成功
```

**检查端口占用**：
```bash
# 检查8000端口
lsof -i :8000

# 检查5174端口
lsof -i :5174

# 如果被占用，杀死进程
kill -9 <PID>
```

---

### Q5: 生成失败，提示"API错误"

**原因**：API密钥无效或配额不足

**解决方法**：

**检查API密钥**：
```bash
# 查看.env文件
cat backend/.env | grep DOLPHIN_API_KEY
```

确保：
- 密钥完整（通常很长）
- 没有多余的空格
- 格式正确

---

### Q6: 图片无法显示或下载失败

**原因**：网络问题或图片源不可用

**解决方法**：

**检查网络**：
```bash
# 测试网络连接
ping google.com
```

**重新生成**：
```
1. 点击"重新生成"
2. 或上传自己的产品图片
3. 系统会使用您上传的图片
```

## 🍎 macOS特别说明

### 终端快捷键

| 快捷键 | 功能 |
|--------|------|
| `Command + 空格` | 打开Spotlight搜索 |
| `Control + C` | 停止当前进程 |
| `Command + Q` | 退出应用 |
| `Command + T` | 新建终端标签 |
| `Command + W` | 关闭当前标签 |

### 文件路径说明

macOS使用 `/` 作为路径分隔符：
```bash
# macOS路径
~/Desktop/网页重置/backend

# Windows路径（对比）
C:\Users\用户名\Desktop\网页重置\backend
```

### 显示隐藏文件

在Finder中按 `Command + Shift + .`（点号）可以显示/隐藏以 `.` 开头的文件（如 `.env`）

### 权限问题

macOS对脚本执行有严格的权限控制：
```bash
# 添加执行权限
chmod +x script.sh

# 查看文件权限
ls -la
```

### 安全提示

首次运行脚本时，macOS可能会提示安全警告：
1. 打开"系统偏好设置"
2. 选择"安全性与隐私"
3. 点击"仍要打开"

## 💡 使用技巧

### 技巧1：使用别名简化命令

在 `~/.zshrc` 或 `~/.bash_profile` 中添加：
```bash
alias start-ai="cd ~/Desktop/网页重置 && ./start-services.sh"
alias stop-ai="killall python3 node"
```

然后只需输入 `start-ai` 即可启动系统！

### 技巧2：创建桌面快捷方式

创建一个 `.command` 文件：
```bash
#!/bin/bash
cd ~/Desktop/网页重置
./start-services.sh
```

保存为 `启动AI系统.command`，双击即可运行。
